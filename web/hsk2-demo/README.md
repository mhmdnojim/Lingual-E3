# HSK 2 book preview

This standalone demo covers PDF pages 21–29 of `HSK-2-Textbook.pdf` (printed book pages 1–9). It keeps the bilingual page design and pinyin in its original positions as non-selectable page images.

## Open it

Start the Lingua Books server from the project folder and open:

`http://127.0.0.1:8765/web/hsk2-demo/`

The demo also works as a static site when served from any local web server.

## Included audio

Lesson 1 recordings are copied into `assets/audio`. Their printed track numbers are matched to the activity labels:

| PDF page | Printed page | Track |
| --- | --- | --- |
| 22 | 2 | 01-1, 01-2 |
| 23 | 3 | 01-3, 01-4 |
| 26 | 6 | 01-5 |

The reader has page buttons, direct page entry, keyboard navigation, zoom, fit and full-screen controls. The page scans preserve the book's exercises as shown; this demo does not yet add answer checking or sentence-level text interaction.
